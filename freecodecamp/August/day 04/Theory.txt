Floating-point representation: Numbers like 2.15 often aren't stored exactly. 
Python's rounding rule: If the stored value is exactly halfway between two choices, Python uses round half to even.

# 1. Floating-point representation:
# Computers store numbers in binary (0s and 1s), not decimal.
# Some decimal numbers cannot be represented exactly.
#
# Example:
# 2.15 might actually be stored as:
# 2.1499999999999999
#
# So when Python does:
# round(2.15, 1)
#
# It is not rounding exactly 2.15.
# It is rounding a tiny bit smaller number, which gives:
# 2.1


# 2. Python's rounding rule:
# If a number is exactly halfway between two choices,
# Python uses "round half to even".
#
# Example:
# round(8.25, 1)
#
# Choices:
# 8.2  or  8.3
#
# Both are equally close.
# Python chooses the one with an even last digit:
# 8.2 (because 2 is even)
#
# This prevents rounding errors from always going upward.
