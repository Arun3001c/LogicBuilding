def array_swap(arr):

    return arr

Python design rule (important)

Python splits operations into two categories:
If a method modifies the object in place, it usually returns None.
If it creates a new object, it returns that object.
1. In-place operations → return None
list.append(x)
list.extend(x)
list.sort()
list.reverse()
2. New-object operations → return new list
sorted(arr)
arr[::-1]
