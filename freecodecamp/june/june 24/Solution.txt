1. enumerate() approach (cleaner version of your solution)

Instead of manually using range(len(...)), you iterate with both index + character:

def find_mutations(s1, s2):
    result = []
    for i, (a, b) in enumerate(zip(s1, s2)):
        if a != b:
            result.append(i)
    return result
Idea:
zip(s1, s2) pairs characters
enumerate() gives index

Same logic, more Pythonic.

2. zip() only (no index loop manually)

You still need index, so you track it yourself:

def find_mutations(s1, s2):
    result = []
    i = 0

    for a, b in zip(s1, s2):
        if a != b:
            result.append(i)
        i += 1

    return result
Idea:
focus on character comparison
manually maintain index
3. List comprehension (compact version)
def find_mutations(s1, s2):
    return [i for i, (a, b) in enumerate(zip(s1, s2)) if a != b]
Idea:
same logic, compressed into one line
commonly used in interviews for clean code
4. Using filter() (less common, more functional style)
def find_mutations(s1, s2):
    return list(
        filter(lambda i: s1[i] != s2[i], range(len(s1)))
    )
Idea:
“filter out indexes where mismatch happens”

Less readable, but shows functional programming style.

5. NumPy approach (used in real scientific work)

If this were large DNA data:

import numpy as np

def find_mutations(s1, s2):
    arr1 = np.array(list(s1))
    arr2 = np.array(list(s2))
    return list(np.where(arr1 != arr2)[0])
Idea:
vectorized comparison (very fast)
used in bioinformatics / data science
