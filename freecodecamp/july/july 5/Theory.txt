What algorithm is used?

A 2D grid can be treated as a graph.

Each cell = a node (vertex).
Adjacent cells (up, down, left, right) = edges.

To visit every connected cell, we use a graph traversal algorithm.

There are two common algorithms:

1. Depth First Search (DFS) ⭐ (Most common for Bucket Fill)
Go as deep as possible before coming back.
Usually implemented using recursion.

Example path:

A
|
B
|
C
|
D

Visit:

A → B → C → D
2. Breadth First Search (BFS)
Visit all neighbors first.
Uses a queue.

Example:

    A
   / \
  B   C
 / \
D   E

Visit:

A → B → C → D → E
Is this Greedy?

No.

Greedy algorithms choose the "best" option at every step.

Examples:

Dijkstra
Prim's
Huffman Coding

Bucket fill doesn't choose anything. It simply explores all connected cells.

Is this Dynamic Programming?

No.

Dynamic Programming is used when:

Problems have overlapping subproblems.
Results can be reused (memoization).

Examples:

Fibonacci
Knapsack
Longest Common Subsequence

Bucket fill has no overlapping subproblems.

Is this Flood Fill?

Yes!

The problem itself is called the Flood Fill Algorithm.

Flood Fill is usually implemented using:

DFS ✅
BFS ✅

Paint programs (like MS Paint's paint bucket) use this algorithm.
