Pronic Number
Given a number, determine whether it is a pronic number.

A pronic number is the product of two consecutive integers. For example, 6 is pronic because 2 * 3 = 6.

Tests:
Passed:1. is_pronic(6) should return True.
Passed:2. is_pronic(15) should return False.
Passed:3. is_pronic(12) should return True.
Passed:4. is_pronic(132) should return True.
Passed:5. is_pronic(80) should return False.
Passed:6. is_pronic(0) should return True.
