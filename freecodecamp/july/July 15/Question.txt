Array Chunks
Given an array and a chunk size, return the array split into sub-arrays of that size.

The last chunk may be smaller if the array doesn't divide evenly.
Tests:
Passed:1. chunk_array([1, 2, 3, 4, 5, 6], 3) should return [[1, 2, 3], [4, 5, 6]].
Passed:2. chunk_array([1, "two", 3, "four", 5, "six", 7, "eight"], 2) should return [[1, "two"], [3, "four"], [5, "six"], [7, "eight"]].
Passed:3. chunk_array([1, 2, 3, 4, 5], 3) should return [[1, 2, 3], [4, 5]].
Passed:4. chunk_array(["a", "b", "c", "d", "e"], 1) should return [["a"], ["b"], ["c"], ["d"], ["e"]].
Passed:5. chunk_array([1, 2, 3], 5) should return [[1, 2, 3]].
