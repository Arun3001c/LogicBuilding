# List slicing with a stop index larger than the list length
arr = [10, 20, 30, 40, 50, 60]

print(arr[:7])

# Output: [10, 20, 30, 40, 50, 60]
# Python slicing does not give an error if the stop index is out of range.
# It returns all available elements up to the end of the list.

list[start:stop]
arr[:7] means:
start from index 0 (because start is omitted)
go up to index 6 (because stop index 7 is not included)

Your list indexes are:

Index:  0   1   2   3   4   5
Value: 10  20  30  40  50  60

Python tries to take indexes 0 through 6, but index 6 does not exist. Python slicing does not throw an error for going beyond the list length; it simply takes whatever elements are available.
