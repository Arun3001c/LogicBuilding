In relative_luminance() you do:

temp = rgb

This does not create a copy. temp and rgb refer to the same list, so you're modifying the original input list. If the test framework reuses the same lists, later calculations will be wrong because the RGB values have already been converted.

Use a copy instead:

temp = rgb[:]

or

temp = list(rgb)

here why the channel value not modified

The reason is that channel is just a local loop variable, not a reference to the list element.

In your code:

for channel in rbg:
    print(channel)
    channel = channel // 255

Here's what happens:

channel gets the value of each element (255, 255, 255).

You assign a new value to the local variable:

channel = channel // 255
This does not change the list rbg. It only changes what the local variable channel refers to.

For example:

lst = [10, 20, 30]

for x in lst:
    x = 0

print(lst)

Output:

[10, 20, 30]

The list is unchanged.

How to modify the list

If you actually want to modify the list, iterate over the indices:

def relative_luminance(rgb):
    for i in range(len(rgb)):
        print(rgb[i])
        rgb[i] = rgb[i] // 255
    print(rgb)

relative_luminance([255, 255, 255])

255
[1, 1, 1]
Or create a new list (recommended)

Instead of modifying the original list:

def relative_luminance(rgb):
    new_rgb = [channel // 255 for channel in rgb]
    print(new_rgb)
    return new_rgb
