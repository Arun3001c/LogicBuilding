Letter Distance
Given two strings of equal length, return the sum of the shortest distances between each pair of characters.

The input will only contain lowercase letters
The alphabet is treated as a circle, so the distance between a and z is 1.
Tests:
Passed:1. letter_distance("abc", "bcd") should return 3.
Passed:2. letter_distance("abc", "xyz") should return 9.
Passed:3. letter_distance("encrypt", "decrypt") should return 10.
Passed:4. letter_distance("algorithm", "codeblock") should return 43.
Passed:5. letter_distance("lobster", "penguin") should return 47.
