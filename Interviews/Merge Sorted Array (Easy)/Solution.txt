        else:

//Concatenate and sort (simplest)
def merge_arr(nums1, nums2, m, n):
    return sorted(nums1[:m] + nums2)

This is the most efficient solution.

Instead of creating another list, fill nums1 from the back.

Example:

nums1 = [1,2,3,0,0,0]
nums2 = [2,5,6]

Start from the end.

[1,2,3,0,0,6]
[1,2,3,0,5,6]
[1,2,3,3,5,6]

//Using heapq.merge()

Python has a built-in merge function for sorted iterables.

import heapq

def merge_arr(nums1, nums2, m, n):
    return list(heapq.merge(nums1[:m], nums2))
